# Personal Portfolio Website

A static personal portfolio built with HTML and CSS. The page presents a short introduction, technical interests, contact information, social links, and custom illustrations.

## Technology

- Semantic HTML
- Custom CSS
- Google Fonts
- Static image assets

## Preview locally

Open `index.html` directly in a browser, or serve the directory locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` — page content and sections
- `css/styles.css` — layout, typography, and component styles
- `images/` — profile and technology artwork

## Privacy

This is a public site. Review every phone number, email address, academic identifier, profile photo, and social link in `index.html` before publishing. Keep only information intentionally approved for public contact.
